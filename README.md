# put.gd-site

The landing page for [put.gd desktop](https://github.com/patrick-hudson/put.gd-desktop), served at
<https://app.put.gd/> and as the root page of <https://put.gd/>. Plain HTML, CSS and a little
JavaScript; no build step.

## Layout

| Path | What it is |
| --- | --- |
| `public/index.html` | The page. Everything it references lives under `public/_site/`. |
| `public/_site/site.css`, `site.js` | Styles, the hero animation choreography, the install table. |
| `public/_site/releases.json` | Generated by `tools/releases.py` at deploy time; not committed. |
| `public/_site/shots/` | Real windows from the current nightly on the lab desktops, as WebP. |
| `tools/releases.py` | Builds `releases.json` from the GitHub releases: `stable` is the newest non-prerelease, `nightly` the newest `-nightly.` prerelease. |
| `tools/update-kvs.py` | Writes the `/dl/<channel>/<package>` redirect targets into the CloudFront KeyValueStore. |
| `cloudfront/download-redirect.js` | CloudFront Function on app.put.gd: `/` to `index.html`, `/dl/...` to the current asset. |
| `cloudfront/root-router.js` | CloudFront Function on put.gd: only the bare `/` goes to the page; every upload key keeps working. |
| `.github/workflows/deploy.yml` | Publishes to S3, refreshes the permalinks, invalidates CloudFront. |

## Working on it

```bash
python3 tools/releases.py            # writes public/_site/releases.json
python3 -m http.server 4411 --directory public
```

Then open <http://127.0.0.1:4411/>. The hero animation is pure CSS on a 9 s loop (`--T` in
`site.css`); the selection geometry is in `cqw` units so it tracks the terminal text at any width.

## Deploying

Every push to `main` deploys. The workflow also runs when put.gd-desktop publishes a release
(`repository_dispatch` with type `release-published`), every six hours as a backstop, and by hand
from the Actions tab. It assumes an AWS role through GitHub OIDC; no long-lived keys are stored.

Repository variables: `AWS_DEPLOY_ROLE_ARN`, `SITE_BUCKET`, `CLOUDFRONT_DISTRIBUTION_IDS`
(space separated), `CLOUDFRONT_KVS_ARN`. The `production` environment gates the deploy job.
